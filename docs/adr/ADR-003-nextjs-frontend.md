# ADR-003 — Next.js como frontend oficial único

**Estado:** Aceptado

## Contexto
El proyecto histórico exploró WinForms, Blazor y .NET MAUI.

## Decisión
Reconstruir todas las capacidades de usuario en una aplicación Next.js responsive.

## Consecuencias
- una única base de frontend;
- experiencia consistente;
- menor costo de mantenimiento;
- reemplazo funcional de clientes históricos;
- posibilidad futura de PWA.
